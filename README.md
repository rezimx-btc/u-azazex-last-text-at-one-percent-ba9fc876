One-line joke entry for the [Last Text at One Percent](https://make.fun/c/u-azazex-last-text-at-one-percent-ba9fc876) competition on make.fun: the last text message sent at 1% phone battery.

## The line

> You said never text at 1%, so I deleted that rule, sent this anyway, and my phone restored it as my last words.

## How it works

`main.py` (stdlib only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`):

```sh
python3 main.py
cat /output/entry.txt
```
